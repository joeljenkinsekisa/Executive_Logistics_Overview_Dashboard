# 📌 Project Overview

The **Executive Logistics Overview Dashboard** is an enterprise-level Business Intelligence project developed using **SQL** and **Power BI** to analyze logistics operations, transportation performance, fleet activity, and operational efficiency.

This project transforms raw operational logistics data into actionable executive insights through advanced SQL engineering, KPI modeling, and interactive dashboard reporting.

The dashboard simulates a real-world logistics environment involving:

* Fleet operations
* Shipment management
* Driver analytics
* Revenue intelligence
* Route profitability
* Fuel consumption monitoring
* Freight distribution
* Operational performance tracking
